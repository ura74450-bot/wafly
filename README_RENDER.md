# Sproutbound Co-op

Оригинальный браузерный farming-simulator MVP для двух игроков. Клиент использует Three.js с процедурными визуальными элементами, а сервер синхронизирует комнату, игроков, грядки, культуры, деньги, день/ночь и действия.

## Что уже есть

- комнаты по коду: создайте один и тот же код у двух игроков;
- движение двух игроков по общей ферме;
- 8 культур: пшеница, кукуруза, морковь, томаты, тыква, клубника, картофель и подсолнух;
- посадка, полив, рост по дням, сбор и продажа урожая;
- общий кошелёк и сезонная цель 200 монет;
- декорации: дом, пруд, деревья, камни, заборы, дорожки и 24 грядки;
- NPC с диалогом и основа для расписаний жителей;
- общий день/ночь: нажмите «спать» обоими игроками или одним игроком в одиночной комнате;
- процедурные ассеты без внешних закрытых файлов;
- WebSocket-сервер, health endpoint и Render Blueprint.

## Быстрый локальный запуск

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm --dir server install --frozen-lockfile

# терминал 1
ALLOWED_ORIGINS=http://localhost:3000 pnpm dev:server

# терминал 2
VITE_SERVER_URL=ws://localhost:8787/ws pnpm dev
```

Откройте `http://localhost:3000`, введите код фермы и откройте тот же код во второй вкладке или браузере.

## Деплой через GitHub + Render

1. Создайте новый репозиторий на GitHub.
2. Распакуйте этот ZIP в папку репозитория.
3. Выполните:

```bash
git init
git add .
git commit -m "Initial Sproutbound Co-op"
git branch -M main
git remote add origin https://github.com/YOUR_NAME/YOUR_REPO.git
git push -u origin main
```

4. В Render выберите **New → Blueprint**, подключите GitHub и выберите репозиторий.
5. Render найдёт `render.yaml`, установит Node 22, соберёт клиент и запустит один Web Service.
6. После деплоя откройте URL Render и зайдите в одну комнату с двух устройств.

Сервис отдаёт клиент и WebSocket из одного домена, поэтому в продакшене URL вычисляется автоматически как `wss://ВАШ-ДОМЕН/ws`. Переменная `ALLOWED_ORIGINS` оставлена пустой: для единого домена это безопасный вариант. Если позже вынесете клиент на другой домен, укажите точные origin через запятую, например `https://game.example.com`.

## Управление

- **WASD / стрелки** — движение;
- **1–8** — выбрать семена;
- **P** — посадить выбранную культуру на ближайшую пустую грядку;
- **W** — полить ближайшую грядку;
- **H** — собрать созревшую культуру;
- **E** — поговорить с ближайшим NPC;
- **S** — продать урожай;
- **Z** — лечь спать и перейти к следующему дню.

## Структура

- `src/main.ts` — клиент, Three.js-сцена, HUD и сетевые действия;
- `src/styles/main.css` — интерфейс и адаптивная мобильная панель;
- `server/authoritative_server.mjs` — комнаты, синхронизация и правила фермы;
- `render.yaml` — единый Render Web Service;
- `Dockerfile` — альтернативный Docker-деплой;
- `public/multiplayer/bootstrap.json` — маркер совместимости протокола.

## Важное ограничение MVP

Состояние комнат хранится в памяти Node.js. Перезапуск Render сбрасывает комнаты, культуры и деньги. Для постоянных ферм добавьте базу данных и авторизацию позже. Этот пакет предназначен для дружеского кооператива, а не для рейтинговой игры или защиты от читеров.
